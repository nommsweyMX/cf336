# La Loca Tlacuaque de la Calle Cerrada: Suno paste sheet

A comic diss track in Mexican street slang about the possum that broke into the house on Calle Cerrada. Hard, raspy Monterrey-style barrio rap in the verses; a bouncy schoolyard "¡Culón, colito!" jingle for the hook.

- **Tempo / key:** 90 BPM, D minor
- **Length target:** about 3:00 to 3:20
- **Structure:** spoken intro, three 8-bar verses, three hooks, the patrulla verde bridge, spoken outro

## 1. Title

```
La Loca Tlacuaque de la Calle Cerrada
```

## 5. If Suno gets it wrong

| Problem | Fix |
|---|---|
| Verses come out too clean | Move `raspy gravelly deep male baritone rap vocals` to the very start of the style |
| Hook is rapped, not chanted | Add `children's choir` to each `[Hook]` tag |
| It sounds like a Christmas song | Swap `sleigh bells` for `tambourine jingles` |
| Too pop, too fast or off-genre | Use the short style with the same Exclude list |
| The crowd answers in (parentheses) are sung as lead lines | Delete a few, starting with `(¡ja!)` and `(¡jálale!)` |
| "tlacuaque" is mispronounced | Type `tla-kuá-ke` in the hook only |
| "se mió" is sung as "mío" | Change it to `se meó` in Verse 1 and Hook 1 |
| The chant trips on "¿Quién se mió?" | Change it to `¿Y quién se mió?` |

## 6. Pronunciation

- **tlacuaque** = tla-KWA-keh. This is your spelling. The dictionary word is *tlacuache* (tla-KWA-cheh); it appears 13 times, so a find-and-replace switches it cleanly.
- **Hook:** cu-LÓN | co-LI-to | cu-LÓN | co-LI-to. Holding "LÓN" gives it the bounce.
- **"¿En la viga? ¡A la verga!"** = VEE-gah, then VEHR-gah. This is the "birga" pun: *viga* is the roof beam she came in through.
- **se mió** = mee-OH (two syllables), colloquial for "se meó".
- **Cocas** = KOH-kahs, **sillón** = see-YOHN, **Calle** = KAH-yeh, **personal** = pehr-soh-NAHL.

## 8. Slang glossary

| Term | Meaning |
|---|---|
| tlacuaque | Possum. Your spelling of the dictionary word 'tlacuache' (Nahuatl origin), sung tla-KWA-keh. Feminine throughout: la tlacuaque. |
| Calle Cerrada | Dead-end street, literally 'closed street'. It doubles with 'encerrada' (locked in). |
| culón colito | Big-butt little-tail: your phrase, used as the chant nickname. Culón is the fixed masculine form of the nickname. |
| colita pelada | Bald little tail (possum tails are bare). Pelada also means crude or foul-mouthed. |
| menéale / menea | Shake it / wiggle it. |
| carnal | Bro, homie: literally 'blood brother'. |
| viga / ¡a la verga! | Viga = roof beam (your 'birga'). ¡A la verga! = holy shit / get the hell out. They sound almost the same. |
| ¡aguas! | Heads up! Watch out! |
| panteón | Cemetery. 'Llevárselas al panteón' = send them to the grave. |
| ahí nos vidrios | Joke for 'ahí nos vemos' (see ya) with vidrios (glass) swapped in, so 'glass you later'. |
| taza | Toilet bowl (literally 'cup'). |
| el trono | The throne: everyday Mexican slang for the toilet. |
| le atinó al azulejo | She hit the tile dead on. 'Atinarle' = to hit the target, so it is ironic. |
| pagar piso | To pay the street 'floor tax' (protection money). Here it also means the floor she pooped on. |
| se mió | She peed. Colloquial Mexican for 'se meó'. |
| lavabo | Bathroom sink. |
| mapache de la pulga | Flea-market raccoon, a bootleg raccoon. 'La pulga' is the northern Mexican word for a flea market. |
| bien pedo | Blackout drunk. |
| ¡fuchi! | Ew! Gross! |
| la chancla | The flip-flop: Mom's legendary punishment weapon. |
| se peló | She bolted, she split. |
| alberca | Swimming pool (the Mexican word; elsewhere 'piscina'). |
| flotando de muertita | Floating on her back. From 'hacer el muertito' (literally 'playing the little dead guy'), put in the feminine here, and a nod to possums playing dead. |
| al cuarto pa' las doce | At a quarter to twelve: at the very last second, just in time. |
| de un chingazo | In one go, in a flash (vulgar). |
| la chapa | The door lock. |
| ¡no mames! | No fucking way! / You're kidding me! |
| cabrona | Sly bitch, tough cookie. In this song it is aimed at the animal. |
| desgraciada | Wretch, rotten thing. |
| la patrulla verde / los de verde | The green patrol, the green-uniformed crew that picks up wild animals. |
| troca | Truck: an everyday northern Mexican word, borrowed from English long ago. |
| más verdes que un nopal | Greener than a cactus paddle. |
| Cocas | Coca-Colas. |
| pollo asado | Charcoal-grilled chicken, a Monterrey staple. |
| carnada | Bait. |
| lonche | Lunch, a packed meal: an everyday northern Mexican word, borrowed from English long ago. |
| personal | The staff, the crew (stressed per-so-NAL). |
| rabito | Little tail. |
| ¡jálale! | Pull it! Yank it! |
| hacerse la muertita / teatrito | To play dead / a little theatrical act, a bit of drama. |
| pinche | Damn, lousy: the all-purpose Mexican put-down adjective. |
| mi reina | My queen. Mock-sweet here. |
| trapeador con dientes | Mop with teeth. |
| peluche de basurero | Dumpster plush toy. |
| de pilón | Thrown in free, the extra a vendor adds. |
| se acabó el rollo | That's the whole story, that's all folks. |
| uiu, uiu | Siren sound (wee-oo). |
